## English

A landing page for a handmade-goods shop built with the Bootstrap grid: a header, a hero banner, four category cards (Kitchen, Woodwork, Gifts, Antique) and a footer with social icons. A Full Stack course lesson on responsive layout.

**Live demo:** https://dubnovalexey.github.io/L_12_HandCrafts/

### Try it

Use Newest, Catalog and See all to move between sections. Resize the page to compare one- and two-column category layouts; inspect the image crops and footer.

### What is inside

- Bootstrap 5 grid with `sm` breakpoints: cards go from one column on a phone to two on a wider screen.
- A full-width hero with a background image and a fluid heading size (`clamp`).
- Images scale with the column (`w-100`).

- Menu links and "See all" navigate to the existing page sections.

### Tech stack

HTML5 · CSS3 · Bootstrap 5 · GitHub Pages

### Run locally

Open `index.html` in a browser.

### Demo scope

This is a presentation landing page, not an operating shop: categories are examples, social icons are decorative, and there is no checkout or message delivery.

### Further development

Proposals below are planned work, not existing features.

- Visual: standardize category image crops and spacing.
- Engineering: add a main landmark, pin local Bootstrap assets and check section anchors automatically.
- Features: populate a small JSON catalog with category filters and product details; configure a real contact destination separately.

## Русский

Лендинг магазина изделий ручной работы на сетке Bootstrap: шапка, баннер, четыре карточки категорий (Kitchen, Woodwork, Gifts, Antique) и подвал со значками соцсетей. Урок курса Full Stack по адаптивной вёрстке.

**Демо:** https://dubnovalexey.github.io/L_12_HandCrafts/

### Попробовать

Проверьте переходы Newest, Catalog и See all между разделами. Измените ширину страницы и сравните одну и две колонки категорий, кадрирование изображений и подвал.

### Что внутри

- Сетка Bootstrap 5 с точкой перелома `sm`: на телефоне карточки в одну колонку, на широком экране — в две.
- Баннер во всю ширину с фоновой картинкой и «резиновым» заголовком (`clamp`).
- Картинки подстраиваются под колонку (`w-100`).

- Меню и «See all» переходят к существующим разделам страницы.

### Стек

HTML5 · CSS3 · Bootstrap 5 · GitHub Pages

### Как запустить

Откройте `index.html` в браузере.

### Границы демонстрации

Это демонстрационный лендинг: категории служат примерами, значки соцсетей декоративные, оформления заказа и отправки сообщений нет.

### Дальнейшее развитие

Ниже перечислены предложения, а не уже реализованные функции.

- Визуал: единое кадрирование карточек и отступы.
- Инженерия: основной landmark main, локальные ресурсы Bootstrap и автоматическая проверка якорей разделов.
- Функции: небольшой JSON-каталог с фильтрами категорий и карточкой изделия; реальный контакт подключать отдельно.
