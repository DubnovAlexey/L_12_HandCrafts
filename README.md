## English

A landing page for a handmade-goods shop built with the Bootstrap grid: a header, a hero banner, four category cards (Kitchen, Woodwork, Gifts, Antique) and a footer with social icons. A Full Stack course lesson on responsive layout.

**Live demo:** https://dubnovalexey.github.io/L_12_HandCrafts/

### Try it

Use Newest, Catalog and See all to move between sections. Resize the page to compare one- and two-column category layouts; inspect the image crops and footer.

### What is inside

- Bootstrap 5 grid with `sm` breakpoints: cards go from one column on a phone to two on a wider screen.
- A full-width hero with a background image and a fluid heading size (`clamp`).
- Images scale with the column (`w-100`).

- Menu links and "See all" navigate to the existing page sections.

### Tech stack

HTML5 · CSS3 · Bootstrap 5 · GitHub Pages

### Run locally

Open `index.html` in a browser.

### Demo scope

This is a presentation landing page, not an operating shop: categories are examples, social icons are decorative, and there is no checkout or message delivery.

### Further development

Proposals below are planned work, not existing features.

- Visual: standardize category image crops and spacing.
- Engineering: add a main landmark, pin local Bootstrap assets and check section anchors automatically.
- Features: populate a small JSON catalog with category filters and product details; configure a real contact destination separately.

## Français

Page vitrine d'une boutique d'artisanat sur la grille Bootstrap : en-tête, bannière, quatre cartes de catégories (Kitchen, Woodwork, Gifts, Antique) et un pied de page avec des icônes de réseaux sociaux. Une leçon du cours Full Stack sur la mise en page adaptative.

**Démo :** https://dubnovalexey.github.io/L_12_HandCrafts/

### À essayer

Vérifiez les liens Newest, Catalog et See all entre les sections. Changez la largeur de la page et comparez une et deux colonnes de catégories, le cadrage des images et le pied de page.

### Ce qu'il y a dedans

- Grille Bootstrap 5 avec le point de rupture `sm` : sur téléphone, les cartes sont sur une colonne ; sur grand écran, sur deux.
- Bannière pleine largeur avec image de fond et titre fluide (`clamp`).
- Les images s'adaptent à la colonne (`w-100`).
- Le menu et « See all » mènent à des sections qui existent sur la page.

### Technologies

HTML5 · CSS3 · Bootstrap 5 · GitHub Pages

### Lancer le projet

Ouvrez `index.html` dans le navigateur.

### Limites de la démo

C'est une page de démonstration : les catégories sont des exemples, les icônes de réseaux sociaux sont décoratives, et il n'y a ni commande ni envoi de messages.

### Évolutions possibles

Ce qui suit sont des propositions, pas des fonctions déjà réalisées.

- Visuel : cadrage et marges homogènes des cartes.
- Ingénierie : un landmark main principal, des ressources Bootstrap locales et une vérification automatique des ancres des sections.
- Fonctions : un petit catalogue JSON avec filtres par catégorie et fiche produit ; un vrai contact serait branché à part.
